Sistem Tanya Jawab Informasi Keuangan

Sistem ini memanfaatkan teknologi Artificial Intelligence untuk membantu pengguna memperoleh informasi keuangan secara cepat, akurat, dan relevan menggunakan semantic search berbasis embedding.

Model yang Digunakan

E5-base-v2

Mengubah pertanyaan pengguna menjadi representasi vektor (embedding) sehingga dapat dilakukan semantic similarity search menggunakan FAISS.

FAISS

Digunakan sebagai vector database untuk mencari dokumen atau jawaban yang memiliki tingkat kemiripan paling tinggi terhadap pertanyaan pengguna.

IndoBERT

Model bahasa yang dilatih menggunakan korpus Bahasa Indonesia. Pada penelitian ini, IndoBERT digunakan untuk mengubah pertanyaan pengguna menjadi representasi vektor (embedding) sehingga dapat dilakukan semantic similarity search menggunakan FAISS pada data berbahasa Indonesia.

Dataset

Nama Dataset

FINQA (Financial Question Answering)

Format Data

JSON

Kolom Dataset

Question, Answer, Text

Tujuan

  • Mengembangkan sistem tanya jawab berbasis Natural Language Processing.
  • Membantu pengguna memperoleh informasi keuangan.
  • Menampilkan jawaban yang paling relevan berdasarkan semantic search.
  • Menampilkan konteks informasi agar pengguna lebih memahami jawaban.

Manfaat

  • Mempermudah pencarian informasi finansial.
  • Memberikan jawaban beserta konteks pendukung.
  • Mendukung proses pembelajaran mengenai laporan keuangan.
  • Mengimplementasikan Artificial Intelligence dalam bidang keuangan.
